# shop relier — 公式サイト

shop relier(ショップ ルリエ)のホームページです。ビルド不要の静的サイト(HTML/CSS/JS)で、GitHub Pages で公開しています。

## 構成

- `index.html` — トップページ
- `shop.html` — オンラインショップ(BASEへの導線)
- `artists.html` — 取扱作家(春夏秋冬の会期ごと)
- `sweets.html` — お菓子の作家さん
- `order.html` — オーダー・名入れ
- `js/products.js` — 商品データ(ここを編集すると一覧が更新されます)
- `js/artists.js` — 作家データ・現在の会期設定(`CURRENT_SEASON`)

## 更新方法

このフォルダの中身を直接編集して commit・push すれば、数分で公開サイトに反映されます。
