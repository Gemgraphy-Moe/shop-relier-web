# 作家さん詳細ページの置き場所

ここには、作家さん1人ずつの詳細ページ(HTMLファイル)を置きます。

## 作り方

1. 管理者サイトの「**作家ポートフォリオ**」で、作家さんの紹介文・写真などを入力
2. 「**HP用に書き出す**」→「ファイルとしてダウンロード」
3. ダウンロードしたHTMLファイルを、このフォルダにそのまま保存
4. `js/artists.js` の該当作家さんのデータに `detailUrl: "artists/ファイル名.html"` を追加

これで「取扱作家」「お菓子の作家さん」ページのカードが、そのままクリックできるリンクになります(`detailUrl` が無い作家さんのカードは今まで通りクリックできません)。

保存したら commit・push すれば、数分で公開サイトに反映されます。
